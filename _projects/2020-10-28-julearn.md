In the same way as [seaborn](https://seaborn.pydata.org) provides an abstraction of [matplotlib's](https://matplotlib.org) functionality aiming for powerful data visualization with minor coding, we built julearn on top of [scikit-learn](https://scikit-learn.org/stable/).

julearn lets users evaluate machine learning models directly from [pandas](https://pandas.pydata.org) dataframes, while keeping the flexibility of scikit-learn's models.

julearn is developed and maintained at the [Applied Machine Learning group](https://www.fz-juelich.de/en/inm/inm-7/research-groups/applied-machine-learning-aml) at Forschungszentrum Jülich. It was the JuRSE Code Pick of the Month in [May 2025](https://www.fz-juelich.de/en/rse/jurse-community/jurse-code-of-the-month/may-2025).

```
pip install julearn
```
